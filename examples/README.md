# Example recording

`sample.mp3` is a 40-second Hebrew reading of the Hebrew Wikipedia article
"עשנן יהודה" (*Fumaria judaica*), for trying out hebrew-stt:

```bash
hebrew-stt examples/sample.mp3
```

**Source:** [Fumaria judaica.ogg](https://commons.wikimedia.org/wiki/File:Fumaria_judaica.ogg)
by Ariel Palmon, from Wikimedia Commons, licensed
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
**Changes:** trimmed to 0:14.5–0:54 and converted to mono MP3.
